# NachUI brand

The NachUI mark is called **Lift**: a block with its top right corner taken out and set beside it. The rounded corner shows the piece came from the block. That is the product in one picture: you take a component, the library keeps its shape, and the copy is yours.

Everything in this folder is generated by `tools/build.sh` from `tools/lift.py` (geometry) and `tools/build.py` (variants, icons, motion). Change the numbers there and rebuild; never edit an exported file by hand.

## Files

| Folder            | What is in it                                                                                     |
| ----------------- | ------------------------------------------------------------------------------------------------- |
| `logo/symbol`     | The mark alone                                                                                    |
| `logo/horizontal` | Symbol and wordmark side by side, the default lockup                                              |
| `logo/stacked`    | Symbol above the wordmark, for square spaces                                                      |
| `logo/wordmark`   | The name alone, for places that already show the symbol                                           |
| `logo/png`        | 1024px symbols and 240px tall lockups for tools that can't take SVG                               |
| `icons`           | `favicon.svg` (follows the system theme), `favicon.ico`, PNG favicons, app icons, avatar, OG card |
| `motion`          | Self-contained animated SVGs: logo intro, symbol intro and a loader                               |

Every logo comes in five colorways: `ink`, `paper`, `two-tone`, `two-tone-reversed` and `current` (inherits `currentColor`, for inline use in the site and in components).

## Geometry

- Symbol on a 100 unit grid: block 68, piece 28, piece moved 18 up and 18 right, radius 16 on outer corners only. The cut corners stay sharp.
- Wordmark: custom squared grotesk, cap height 100, x-height 72, vertical strokes 19, horizontal strokes 16.5, outer radius 16, inner radius 6.
- Horizontal lockup: the block is exactly cap height and sits on the baseline, so the piece rises above the name. Gap from symbol to wordmark is 30 units.
- Favicons use hinted versions drawn on a 16 and a 32 pixel grid, not the scaled vector.

## Clear space and minimum size

- Keep clear space equal to the piece (28 units at symbol scale) on every side.
- Symbol: 16px minimum. Below 24px use the hinted favicon files.
- Horizontal lockup: 72px wide minimum. Stacked lockup: 48px wide minimum.

| Paper     | `#ffffff` | `oklch(100% 0 0)`        | The mark on dark grounds              |
| Sky       | `#0072a0` | `oklch(52% 0.115 234)`   | The piece on light grounds, links     |
| Sky Light | `#80d0f6` | `oklch(82% 0.095 230)`   | The piece on dark grounds             |

These are the same values as the site's tokens in `packages/ui/tokens/themes/nachui`, so the brand and the product never drift. Sky is the only brand hue. In the two-tone mark only the piece takes it, because the piece is the part that becomes yours.

Contrast: Sky on Paper 5.4:1, Ink on Sky Light 10.8:1, Sky Deep on Sky Light 10.0:1, Graphite on Paper 7.1:1.

## Typography

- The wordmark is drawn, not typed. Never set "NachUI" in a font as a logo.
- Display and headings: Bricolage Grotesque, semibold, tracking around -0.03em.
- Text: Hanken Grotesk.
- Code, labels and metadata: DM Mono.

These are the fonts the docs site already ships, so nothing new has to load.

## Motion

- Intro: the block fades in with the piece seated, the piece lifts out on a small overshoot, then the name wipes in. About 1.6s.
- Loader: the piece seats and lifts on a 1.6s loop.
- Hover: the piece nudges a few units further out. Nothing else moves.
- Easing for the lift is `cubic-bezier(.3, 1.45, .55, 1)`. Every animation stops under `prefers-reduced-motion` and shows the finished mark.

## Don't

- Don't move, resize or rotate the piece, or close the gap.
- Don't round the cut corners or square the outer ones.
- Don't color the block in Sky or the piece in anything but Sky, Sky Light or the mark's own color.
- Don't add gradients, shadows, outlines or effects.
- Don't stretch, rotate or rebuild the wordmark in a font.
- Don't place the mark on busy images or on grounds without enough contrast.
