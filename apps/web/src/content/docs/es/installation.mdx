NachUI es React y Tailwind CSS sin más, así que funciona en cualquier proyecto con React 19. Lo más rápido es `nachui init`, que hace todo lo de esta página en un solo comando (mira [Empezar](/docs)). Esta guía recorre los mismos pasos a mano, para cuando quieres ver cada pieza o no puedes usar el CLI. Lleva unos minutos y se hace una sola vez.

<Callout variant="info">
  <Callout.Title>Requisitos previos</Callout.Title>
  <Callout.Content>Antes de comenzar, asegúrate de que tu proyecto tenga:</Callout.Content>
</Callout>

- **React 19+**
- **Tailwind CSS v4**
- **TypeScript** (recomendado, el código fuente está escrito en TypeScript)
- **Node.js 20+**

## No depende de Next.js

Muchos componentes empiezan con `'use client'`. Esa línea es una directiva de React, no algo propio de Next.js. Los frameworks que usan React Server Components (como el App Router de Next.js) la leen para saber qué archivos corren en el navegador. En el resto, como Vite, TanStack Start o React Router, es un string que el bundler ignora. Puedes dejarla en cualquier setup.

Los componentes solo importan de `react`, `react-dom`, `motion`, `clsx`, `tailwind-merge` y `class-variance-authority`. No usan router, ni cargador de fuentes, ni APIs de ningún framework.

<TabsContent value="vite" className="mt-5">

Crea una app con React y TypeScript, y después agrega Tailwind CSS con su plugin de Vite:

```bash
npm create vite@latest my-app -- --template react-ts
cd my-app
npm install tailwindcss @tailwindcss/vite
```

Registra el plugin junto al de React:

```ts title="vite.config.ts"
import tailwindcss from '@tailwindcss/vite';
import react from '@vitejs/plugin-react';
import { defineConfig } from 'vite';

export default defineConfig({
  plugins: [react(), tailwindcss()],
});
```

- **Carpeta de código:** `src/`
- **Hoja de estilos principal:** `src/index.css`, que ya se importa en `src/main.tsx`

#### Instala las dependencias

<PackageManagerTabs command="motion clsx tailwind-merge class-variance-authority" />

Estas librerías se usan para:

- **motion**: animaciones y transiciones
- **clsx**: construir clases de forma condicional
- **tailwind-merge**: combinar clases de Tailwind sin conflictos
- **class-variance-authority**: variantes de los componentes

Los iconos no necesitan ningún paquete extra. Los componentes traen sus propios SVG, y el [set de iconos de NachUI](/icons), que es opcional, es un archivo por icono que copias igual que un componente. También sirve cualquier otra librería de iconos, porque todos los componentes los reciben por props.

#### Agrega el helper `cn`

Dentro de tu carpeta de código, crea el helper que usan todos los componentes para combinar clases:

```typescript title="src/lib/cn.ts"
import { clsx, type ClassValue } from 'clsx';
import { twMerge } from 'tailwind-merge';

export function cn(...inputs: ClassValue[]) {
  return twMerge(clsx(inputs));
}
```

#### Agrega los tokens de movimiento

Junto a `cn`, crea el archivo que guarda el vocabulario de animación. Cada componente que se mueve lee sus springs y variantes de acá, así toda la librería comparte un mismo material físico y lo ajustas en un solo lugar:

```typescript title="src/lib/motion.ts"
import type { Transition, Variants } from 'motion/react';

const spring = (stiffness: number, damping: number, mass: number): Transition => ({
  type: 'spring',
  stiffness,
  damping,
  mass,
});

export const springs = {
  snappy: spring(550, 22, 0.6),
  smooth: spring(380, 24, 0.8),
  gentle: spring(200, 20, 1),
};

export const still: Transition = { duration: 0 };

export const tap = { scale: 0.94 };

export const reveal: Variants = {
  hidden: { opacity: 0 },
  visible: { opacity: 1, transition: { duration: 0.12 } },
  exit: { opacity: 0, transition: { duration: 0.08 } },
};

export type FloatingSide = 'top' | 'bottom' | 'left' | 'right';

const ENTER_OFFSET = 10;
const EXIT_OFFSET = 4;

const towards = (side: FloatingSide, distance: number) => {
  switch (side) {
    case 'top':
      return { y: distance };
    case 'bottom':
      return { y: -distance };
    case 'left':
      return { x: distance };
    case 'right':
      return { x: -distance };
  }
};

const floating = (side: FloatingSide): Variants => ({
  hidden: { opacity: 0, scale: 0.85, filter: 'blur(6px)', ...towards(side, ENTER_OFFSET) },
  visible: {
    opacity: 1,
    scale: 1,
    filter: 'blur(0px)',
    x: 0,
    y: 0,
    transition: { ...springs.smooth, opacity: { duration: 0.16 }, filter: { duration: 0.2 } },
  },
  exit: {
    opacity: 0,
    scale: 0.92,
    filter: 'blur(4px)',
    ...towards(side, EXIT_OFFSET),
    transition: { duration: 0.12, ease: 'easeIn' },
  },
});

export const floatingVariants: Record<FloatingSide, Variants> = {
  top: floating('top'),
  bottom: floating('bottom'),
  left: floating('left'),
  right: floating('right'),
};

export const floatingOrigin: Record<FloatingSide, string> = {
  top: 'origin-bottom',
  bottom: 'origin-top',
  left: 'origin-right',
  right: 'origin-left',
};

export const backdrop: Variants = {
  hidden: { opacity: 0 },
  visible: { opacity: 1, transition: { duration: 0.25 } },
  exit: { opacity: 0, transition: { duration: 0.15 } },
};

export const surface: Variants = {
  hidden: { opacity: 0, scale: 0.85, y: 16, filter: 'blur(10px)' },
  visible: {
    opacity: 1,
    scale: 1,
    y: 0,
    filter: 'blur(0px)',
    transition: { ...springs.gentle, opacity: { duration: 0.18 }, filter: { duration: 0.25 } },
  },
  exit: {
    opacity: 0,
    scale: 0.9,
    y: 12,
    filter: 'blur(8px)',
    transition: { duration: 0.16, ease: 'easeIn' },
  },
};

const offscreen = (side: FloatingSide, amount: string) => {
  switch (side) {
    case 'top':
      return { y: `-${amount}` };
    case 'bottom':
      return { y: amount };
    case 'left':
      return { x: `-${amount}` };
    case 'right':
      return { x: amount };
  }
};

const slide = (side: FloatingSide): Variants => ({
  hidden: offscreen(side, '100%'),
  visible: { x: 0, y: 0, transition: springs.gentle },
  exit: { ...offscreen(side, '110%'), transition: { duration: 0.2, ease: 'easeIn' } },
});

export const slideVariants: Record<FloatingSide, Variants> = {
  top: slide('top'),
  bottom: slide('bottom'),
  left: slide('left'),
  right: slide('right'),
};

export const collapse: Variants = {
  closed: {
    height: 0,
    opacity: 0,
    transition: { height: springs.snappy, opacity: { duration: 0.1 } },
  },
  open: {
    height: 'auto',
    opacity: 1,
    transition: { height: springs.smooth, opacity: { duration: 0.2, delay: 0.04 } },
  },
};

export const collapseInner: Variants = {
  closed: { y: -10, scale: 0.97, filter: 'blur(4px)', transition: { duration: 0.12 } },
  open: { y: 0, scale: 1, filter: 'blur(0px)', transition: springs.smooth },
};

export const pop: Variants = {
  hidden: { opacity: 0, scale: 0.6 },
  visible: { opacity: 1, scale: 1, transition: { ...springs.snappy, opacity: { duration: 0.1 } } },
  exit: { opacity: 0, scale: 0.8, transition: { duration: 0.1, ease: 'easeIn' } },
};

export const cascade = {
  list: {
    hidden: {},
    visible: { transition: { staggerChildren: 0.035, delayChildren: 0.02 } },
  },
  item: {
    hidden: { opacity: 0, y: 8, scale: 0.9, filter: 'blur(4px)' },
    visible: { opacity: 1, y: 0, scale: 1, filter: 'blur(0px)', transition: springs.snappy },
  },
} satisfies Record<string, Variants>;
```

Tres springs cubren todo. `snappy` es para hover, press y toggles, `smooth` para paneles, menús y collapsibles, y `gentle` para las superficies grandes como los diálogos. Los elementos flotantes abren desde el lado de su trigger y se van más rápido de lo que llegaron.

#### Agrega los helpers de estado, overlays y posicionamiento

En `lib/` viven tres archivos más, y solo los necesitas cuando agregas un componente que los importa:

- [`use-controllable-state.ts`](https://github.com/figueroaignacio/nachui/blob/main/packages/ui/src/lib/use-controllable-state.ts) permite que un componente funcione de las dos maneras: le pasas `value` u `open` y lo controlas tú, o no los pasas y él maneja su propio estado. La mayoría de los componentes con estado lo usan.
- [`overlay.ts`](https://github.com/figueroaignacio/nachui/blob/main/packages/ui/src/lib/overlay.ts) tiene lo que comparten los diálogos, sheets, drawers, menús y toasts: el bloqueo del scroll, el focus trap y la pila de capas abiertas, para que Escape cierre solo la que está arriba.
- [`floating.ts`](https://github.com/figueroaignacio/nachui/blob/main/packages/ui/src/lib/floating.ts) ubica popovers, tooltips, menús y selects junto a su trigger. Los pasa al otro lado cuando no hay lugar, los mantiene dentro de la pantalla y los renderiza al final de la página para que un padre con `overflow: hidden` no los corte.

Si un archivo que pegas importa `../lib/use-controllable-state`, `../lib/overlay` o `../lib/floating`, copia ese helper en `src/lib/`, junto a `cn.ts`. La CLI lo hace por ti.

Los elementos AI comparten un archivo más, [`arrival.ts`](https://github.com/figueroaignacio/nachui/blob/main/packages/ui/src/lib/arrival.ts). Es lo que hace que un mensaje nuevo, un paso terminado o un contador se animen cuando cambian, y se queden quietos cuando la página carga. Sus cuatro animaciones (`arrive`, `token`, `status` y `roll`) son keyframes comunes: cópialas de [`globals.css`](https://github.com/figueroaignacio/nachui/blob/main/packages/ui/src/css/globals.css) junto con sus líneas `--animate-*` de `@theme`.

## Agrega tu primer componente

1. Abre la página del componente que quieres, por ejemplo [Button](/docs/elements/ui/button).
2. Copia el código desde la pestaña **Manual**.
3. Pégalo en la carpeta que corresponde, en este caso `src/components/button.tsx`.
4. Si la página indica dependencias extra, instálalas.
5. Impórtalo y úsalo:

```tsx
import { Button } from './components/button';

export function App() {
  return <Button>Deploy</Button>;
}
```

Algunos componentes usan otros. Cuando un archivo importa algo como `./label` o `../components/dialog`, copia ese componente también.

## Modo oscuro

El tema oscuro se activa cuando el elemento `<html>` tiene la clase `dark`. Alterna esa clase de la forma en que tu app maneje el cambio de tema.
