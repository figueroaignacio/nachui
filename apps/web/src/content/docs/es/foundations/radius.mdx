Las esquinas en NachUI son suaves: los controles se leen como pastillas y las superficies se curvan como el borde de un dispositivo. Todos los radios salen de un solo token, `--radius`, que vale `1.125rem` (18px) en el tema `nachui`. Si lo cambiás, toda la escala se mueve junta.

## La escala

Las utilidades de radio de Tailwind se derivan de la base con multiplicadores fijos. Las cajas de abajo usan las utilidades reales, así que siguen el tema del sitio.

<RadiusScale locale="es" />

| Utilidad      | Fórmula           | Con 1.125rem | Uso                                                             |
| ------------- | ----------------- | ------------ | --------------------------------------------------------------- |
| `rounded-sm`  | `--radius * 0.66` | 12px         | Ítems dentro de una superficie: menú, pastilla de tabs, tooltip |
| `rounded-md`  | `--radius`        | 18px         | Controles, superficies flotantes, toasts, callouts              |
| `rounded-lg`  | `--radius * 1.33` | 24px         | Contenedores principales: cards, diálogos                       |
| `rounded-xl`  | `--radius * 1.66` | 30px         | Contenedores de redacción como el prompt input                  |
| `rounded-2xl` | `--radius * 2`    | 36px         | Drawers y otros paneles grandes                                 |

```css
@theme inline {
  --radius-sm: calc(var(--radius) * 0.66);
  --radius-md: var(--radius);
  --radius-lg: calc(var(--radius) * 1.33);
  --radius-xl: calc(var(--radius) * 1.66);
  --radius-2xl: calc(var(--radius) * 2);
}
```

Los botones, inputs y triggers de select usan `rounded-md`. Con la base de `nachui` eso es la mitad del alto de un control de 36px, así que se leen como pastillas; un tema con una base más chica, como `microsoft`, los deja más rectos sin tocar ningún componente. `rounded-full` queda para lo que es redondo en todos los temas: avatares, puntos de estado, botones redondos de solo ícono y chips.

El checkbox es la única excepción por debajo de la escala, con `--radius * 0.33` (6px). Con 16px de ancho, `rounded-sm` lo haría parecer un radio.

## Anidado

Un elemento dentro de otro siempre usa un radio menor que su contenedor. Un menú (`rounded-md`) tiene ítems con `rounded-sm`; una card (`rounded-lg`) tiene controles con `rounded-md`. Cuando la esquina interior es igual a la exterior, el espacio entre las dos se ve desparejo y el elemento de adentro parece inflado.

<RadiusNesting locale="es" />

Una forma rápida de chequearlo: si ves que la curva de la esquina interior tiene el mismo tamaño que la de afuera, bajala un paso.
