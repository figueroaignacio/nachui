## Anatomía

```tsx
import { Table } from '@/components/ui/table';
```

```tsx
<Table>
  <Table.Caption>A list of your recent invoices.</Table.Caption>
  <Table.Header>
    <Table.Row>
      <Table.Head>Head</Table.Head>
    </Table.Row>
  </Table.Header>
  <Table.Body>
    <Table.Row>
      <Table.Cell>Cell</Table.Cell>
    </Table.Row>
  </Table.Body>
  <Table.Footer>
    <Table.Row>
      <Table.Cell>Footer</Table.Cell>
    </Table.Row>
  </Table.Footer>
</Table>
```

## Composición

Usa la siguiente composición para construir un `Table`:

```tree
Table
├── Table.Caption
├── Table.Header
│   └── Table.Row
│       └── Table.Head
├── Table.Body
│   └── Table.Row
│       └── Table.Cell
└── Table.Footer
    └── Table.Row
        └── Table.Cell
```
