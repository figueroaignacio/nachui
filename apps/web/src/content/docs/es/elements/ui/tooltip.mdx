## Anatomía

```tsx
import { Tooltip } from '@/components/ui/tooltip';
```

```tsx
<Tooltip>
  <Tooltip.Trigger asChild>
    <Button variant="outline">Pasa el mouse</Button>
  </Tooltip.Trigger>
  <Tooltip.Content>
    <p>Texto de tooltip útil</p>
  </Tooltip.Content>
</Tooltip>
```

El tooltip se abre después de `delayDuration` con hover y al instante con el foco del teclado. Podés mover el puntero encima sin que se cierre, y `Escape` lo cierra sin cerrar el dialog o sheet que lo contiene. Se renderiza en un portal, así que un padre con `overflow: hidden` nunca lo recorta, y se da vuelta o se corre para quedar en pantalla.

En pantallas táctiles se abre con una pulsación larga y se cierra con el siguiente toque afuera. Como casi nadie hace pulsación larga, el tooltip tiene que sumar detalle y no ser la única etiqueta: los botones de ícono también necesitan un `aria-label`.

Usá `asChild` para engancharlo a tu propio botón. Sin `asChild` el trigger envuelve a sus hijos en un `span`, que es enfocable cuando el contenido es texto y se corre cuando el hijo ya es enfocable, así nunca quedan dos paradas de tabulación.

## Composición

Usa la siguiente composición para construir un `Tooltip`:

```tree
Tooltip
├── Tooltip.Trigger
└── Tooltip.Content
```

## Características

- **Múltiples posiciones** - Colocación arriba, abajo, izquierda o derecha
- **Control de retraso** - Retraso de hover configurable
- **Animaciones suaves** - Efectos de entrada con desvanecimiento y desenfoque
- **Indicador de flecha** - Puntero visual al elemento activador

## Referencia de API

### Tooltip

| Prop            | Tipo                      | Por defecto | Descripción                                      |
| --------------- | ------------------------- | ----------- | ------------------------------------------------ |
| `delayDuration` | `number`                  | `200`       | Retraso antes de mostrar (ms)                    |
| `defaultOpen`   | `boolean`                 | `false`     | Estado abierto inicial cuando no está controlado |
| `open`          | `boolean`                 | -           | Estado abierto controlado                        |
| `onOpenChange`  | `(open: boolean) => void` | -           | Callback cuando cambia el estado                 |

### Tooltip.Trigger

| Prop        | Tipo      | Por defecto | Descripción                   |
| ----------- | --------- | ----------- | ----------------------------- |
| `asChild`   | `boolean` | `false`     | Renderizar como elemento hijo |
| `className` | `string`  | -           | Clases CSS adicionales        |

### Tooltip.Content

| Prop         | Tipo                                     | Por defecto | Descripción                  |
| ------------ | ---------------------------------------- | ----------- | ---------------------------- |
| `side`       | `'top' \| 'bottom' \| 'left' \| 'right'` | `'top'`     | Posición del tooltip         |
| `sideOffset` | `number`                                 | `4`         | Distancia del activador (px) |
| `className`  | `string`                                 | -           | Clases CSS adicionales       |

## Variantes

### Diferentes Posiciones

```tsx
// Arriba (por defecto)
<Tooltip>
  <Tooltip.Trigger asChild>
    <Button>Arriba</Button>
  </Tooltip.Trigger>
  <Tooltip.Content side="top">
    <p>Tooltip arriba</p>
  </Tooltip.Content>
</Tooltip>

// Abajo
<Tooltip>
  <Tooltip.Trigger asChild>
    <Button>Abajo</Button>
  </Tooltip.Trigger>
  <Tooltip.Content side="bottom">
    <p>Tooltip abajo</p>
  </Tooltip.Content>
</Tooltip>
```

### Retraso Personalizado

```tsx
<Tooltip delayDuration={500}>
  <Tooltip.Trigger asChild>
    <Button>Tooltip lento</Button>
  </Tooltip.Trigger>
  <Tooltip.Content>
    <p>Esto aparece después de 500ms</p>
  </Tooltip.Content>
</Tooltip>
```
