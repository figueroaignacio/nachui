Las piezas que son demasiado grandes para ser un element y demasiado chicas para ser una página. Un chat es un hilo, una respuesta, sus fuentes, una fila de acciones y un composer hablándose entre sí; un hybrid es esa conversación ya cableada.

Siguen las mismas reglas que todo lo demás en NachUI. Abrís el archivo y ves los mismos elements que muestran las docs, en orden, sin lógica escondida en el medio. Props que entran, eventos que salen, sin SDK atado: un adaptador opcional traduce lo que sea que corra tu modelo a esas props.
