## API Reference

### Container

| Prop        | Type                                                | Default    | Description                                                                                                       |
| ----------- | --------------------------------------------------- | ---------- | ----------------------------------------------------------------------------------------------------------------- |
| `as`        | `React.ElementType`                                 | `'div'`    | The element type to render the component as                                                                       |
| `size`      | `'sm' \| 'md' \| 'lg' \| 'xl' \| '2xl' \| 'fluid'`  | `'xl'`     | Container size mapping to max-width breakpoints                                                                   |
| `align`     | `'start' \| 'center' \| 'end' \| 'left' \| 'right'` | `'center'` | Horizontal alignment of the container itself; `left` and `right` follow the text direction like `start` and `end` |
| `className` | `string`                                            | -          | Custom CSS classes                                                                                                |
