The pieces that are too big to be one element and too small to be a page. A chat is a thread, a response, its sources, a row of actions and a composer talking to each other; a hybrid is that conversation already wired.

They follow the same rules as everything else in NachUI. Open the file and you see the same elements the docs show, in order, with no logic hidden between them. Props in, events out, no SDK attached: an optional adapter translates whatever runs your model into those props.
