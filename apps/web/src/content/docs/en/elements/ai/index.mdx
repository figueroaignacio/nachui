The surfaces an AI product needs that a generic component library does not cover: a composer that takes files, a thread that keeps the newest message in view, an answer with a caret while it streams, a tool call with its input and output, the sources behind it, and the row of actions under it.

They follow the same rules as the rest of NachUI. No SDK, no provider lock in, no npm wrapper. You pass the data in through props and wire them to whatever runs your model.
