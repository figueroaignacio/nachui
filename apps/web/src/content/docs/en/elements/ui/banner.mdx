## Anatomy

```tsx
import { Banner } from '@/components/ui/banner';
```

```tsx
<Banner variant="info">
  <Banner.Content>
    <Banner.Title>Announcement</Banner.Title>
    <Banner.Description>Something important happened.</Banner.Description>
  </Banner.Content>
  <Banner.Action href="/changelog">Learn more</Banner.Action>
</Banner>
```

## Composition

Use the following composition to build a `Banner`:

```tree
Banner
├── Banner.Content
│   ├── Banner.Title
│   └── Banner.Description
└── Banner.Action
```

## API Reference

### Banner

| Prop           | Type                                                                | Default            | Description                                                                                                                                      |
| -------------- | ------------------------------------------------------------------- | ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| `variant`      | `"default"` \| `"info"` \| `"warning"` \| `"danger"` \| `"success"` | `"default"`        | Controls the visual treatment and surface colors.                                                                                                |
| `icon`         | `React.ReactNode`                                                   | —                  | Optional custom icon overriding the variant icon.                                                                                                |
| `open`         | `boolean`                                                           | —                  | Controlled visibility.                                                                                                                           |
| `defaultOpen`  | `boolean`                                                           | `true`             | Visibility on first render when uncontrolled.                                                                                                    |
| `onOpenChange` | `(open: boolean) => void`                                           | —                  | Fires when the banner wants to show or hide.                                                                                                     |
| `onClose`      | `() => void`                                                        | —                  | Callback fired when the banner is dismissed.                                                                                                     |
| `dismissible`  | `boolean`                                                           | `true`             | Shows the dismiss button.                                                                                                                        |
| `dismissLabel` | `string`                                                            | `"Dismiss banner"` | Accessible name of the dismiss button.                                                                                                           |
| `sticky`       | `boolean`                                                           | `false`            | Sticks the banner to the top of the viewport.                                                                                                    |
| `role`         | `"region"` \| `"status"` \| `"alert"`                               | `"region"`         | Landmark by default. Use `"alert"` only for a banner you inject in response to something urgent, since screen readers interrupt the user for it. |
| `label`        | `string`                                                            | `"Announcement"`   | Accessible name of the region. Ignored when you pass `aria-label` or `aria-labelledby`.                                                          |
| `className`    | `string`                                                            | —                  | Additional CSS class names.                                                                                                                      |
| `children`     | `React.ReactNode`                                                   | —                  | Compose the banner with Content, Title, and Action.                                                                                              |

### Banner.Content

| Prop        | Type              | Default | Description                  |
| ----------- | ----------------- | ------- | ---------------------------- |
| `children`  | `React.ReactNode` | —       | Wraps Title and Description. |
| `className` | `string`          | —       | Additional CSS class names.  |

### Banner.Title

| Prop        | Type              | Default | Description                  |
| ----------- | ----------------- | ------- | ---------------------------- |
| `children`  | `React.ReactNode` | —       | Heading text for the banner. |
| `className` | `string`          | —       | Additional CSS class names.  |

### Banner.Description

| Prop        | Type              | Default | Description                     |
| ----------- | ----------------- | ------- | ------------------------------- |
| `children`  | `React.ReactNode` | —       | Supporting text for the banner. |
| `className` | `string`          | —       | Additional CSS class names.     |

### Banner.Action

| Prop        | Type              | Default | Description                 |
| ----------- | ----------------- | ------- | --------------------------- |
| `href`      | `string`          | —       | Link destination.           |
| `children`  | `React.ReactNode` | —       | Action label text.          |
| `className` | `string`          | —       | Additional CSS class names. |
