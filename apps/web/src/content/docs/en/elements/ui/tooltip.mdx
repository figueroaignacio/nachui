## Anatomy

```tsx
import { Tooltip } from '@/components/ui/tooltip';
```

```tsx
<Tooltip>
  <Tooltip.Trigger asChild>
    <Button variant="outline">Hover me</Button>
  </Tooltip.Trigger>
  <Tooltip.Content>
    <p>Helpful tooltip text</p>
  </Tooltip.Content>
</Tooltip>
```

The tooltip opens after `delayDuration` on hover and right away on keyboard focus. You can move the pointer onto it without it closing, and `Escape` closes it without closing a dialog or sheet around it. It renders in a portal, so a parent with `overflow: hidden` never clips it, and it flips and shifts to stay on screen.

On touch screens a long press opens it and the next tap outside closes it. Since most people will never long press, a tooltip should add detail, not be the only label: give icon buttons an `aria-label` too.

Use `asChild` to attach the tooltip to your own button. Without it the trigger wraps its children in a `span`, which is focusable for plain text and steps aside when the child is already focusable, so you never get two tab stops.

## Composition

Use the following composition to build a `Tooltip`:

```tree
Tooltip
├── Tooltip.Trigger
└── Tooltip.Content
```

## Features

- **Multiple positions** - Top, bottom, left, or right placement
- **Delay control** - Configurable hover delay
- **Smooth animations** - Fade and blur entrance effects
- **Arrow indicator** - Visual pointer to the trigger element

## API Reference

### Tooltip

| Prop            | Type                      | Default | Description                                  |
| --------------- | ------------------------- | ------- | -------------------------------------------- |
| `delayDuration` | `number`                  | `200`   | Delay before showing (ms)                    |
| `defaultOpen`   | `boolean`                 | `false` | Open state on first render when uncontrolled |
| `open`          | `boolean`                 | -       | Controlled open state                        |
| `onOpenChange`  | `(open: boolean) => void` | -       | Callback when state changes                  |

### Tooltip.Trigger

| Prop        | Type      | Default | Description             |
| ----------- | --------- | ------- | ----------------------- |
| `asChild`   | `boolean` | `false` | Render as child element |
| `className` | `string`  | -       | Additional CSS classes  |

### Tooltip.Content

| Prop         | Type                                     | Default | Description                |
| ------------ | ---------------------------------------- | ------- | -------------------------- |
| `side`       | `'top' \| 'bottom' \| 'left' \| 'right'` | `'top'` | Tooltip position           |
| `sideOffset` | `number`                                 | `4`     | Distance from trigger (px) |
| `className`  | `string`                                 | -       | Additional CSS classes     |

## Variants

### Different Positions

```tsx
// Top (default)
<Tooltip>
  <Tooltip.Trigger asChild>
    <Button>Top</Button>
  </Tooltip.Trigger>
  <Tooltip.Content side="top">
    <p>Tooltip on top</p>
  </Tooltip.Content>
</Tooltip>

// Bottom
<Tooltip>
  <Tooltip.Trigger asChild>
    <Button>Bottom</Button>
  </Tooltip.Trigger>
  <Tooltip.Content side="bottom">
    <p>Tooltip on bottom</p>
  </Tooltip.Content>
</Tooltip>
```

### Custom Delay

```tsx
<Tooltip delayDuration={500}>
  <Tooltip.Trigger asChild>
    <Button>Slow tooltip</Button>
  </Tooltip.Trigger>
  <Tooltip.Content>
    <p>This appears after 500ms</p>
  </Tooltip.Content>
</Tooltip>
```
