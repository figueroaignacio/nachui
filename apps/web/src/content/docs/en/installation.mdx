NachUI is plain React and Tailwind CSS, so it works in any React 19 project. The CLI is still in progress, so for now the setup is manual. It takes a few minutes and you only do it once.

<Callout variant="info">
  <Callout.Title>Prerequisites</Callout.Title>
  <Callout.Content>Before you begin, make sure your project has:</Callout.Content>
</Callout>

- **React 19+**
- **Tailwind CSS v4**
- **TypeScript** (recommended, the source is written in it)
- **Node.js 20+**

## Not tied to Next.js

Many components start with `'use client'`. That line is a React directive, not a Next.js feature. Frameworks that use React Server Components (like the Next.js App Router) read it to know which files run in the browser. Everywhere else, like Vite, TanStack Start or React Router, it is just a string that the bundler ignores. You can keep it in every setup.

The components only import from `react`, `react-dom`, `motion`, `clsx`, `tailwind-merge` and `class-variance-authority`. No router, no font loader and no framework APIs.

#### Install the dependencies

<PackageManagerTabs command="motion clsx tailwind-merge class-variance-authority" />

These libraries are used for:

- **motion**: animations and transitions
- **clsx**: conditional class names
- **tailwind-merge**: merging Tailwind classes without conflicts
- **class-variance-authority**: component variants

Icons need no extra package. The components carry their own SVGs, and the optional [NachUI icon set](/icons) is one file per icon that you copy the same way as a component. Any other icon library works too, since every component takes icons through props.

#### Add the `cn` helper

Inside your source folder, create the helper every component uses to combine classes:

```typescript title="src/lib/cn.ts"
import { clsx, type ClassValue } from 'clsx';
import { twMerge } from 'tailwind-merge';

export function cn(...inputs: ClassValue[]) {
  return twMerge(clsx(inputs));
}
```

#### Add the motion tokens

Next to `cn`, create the file that holds the animation vocabulary. Every component that moves reads its springs and variants from here, so the whole library shares one physical material and you tune it in one place:

```typescript title="src/lib/motion.ts"
import type { Transition, Variants } from 'motion/react';

const spring = (stiffness: number, damping: number, mass: number): Transition => ({
  type: 'spring',
  stiffness,
  damping,
  mass,
});

export const springs = {
  snappy: spring(550, 22, 0.6),
  smooth: spring(380, 24, 0.8),
  gentle: spring(200, 20, 1),
};

export const still: Transition = { duration: 0 };

export const tap = { scale: 0.94 };

export const reveal: Variants = {
  hidden: { opacity: 0 },
  visible: { opacity: 1, transition: { duration: 0.12 } },
  exit: { opacity: 0, transition: { duration: 0.08 } },
};

export type FloatingSide = 'top' | 'bottom' | 'left' | 'right';

const ENTER_OFFSET = 10;
const EXIT_OFFSET = 4;

const towards = (side: FloatingSide, distance: number) => {
  switch (side) {
    case 'top':
      return { y: distance };
    case 'bottom':
      return { y: -distance };
    case 'left':
      return { x: distance };
    case 'right':
      return { x: -distance };
  }
};

const floating = (side: FloatingSide): Variants => ({
  hidden: { opacity: 0, scale: 0.85, filter: 'blur(6px)', ...towards(side, ENTER_OFFSET) },
  visible: {
    opacity: 1,
    scale: 1,
    filter: 'blur(0px)',
    x: 0,
    y: 0,
    transition: { ...springs.smooth, opacity: { duration: 0.16 }, filter: { duration: 0.2 } },
  },
  exit: {
    opacity: 0,
    scale: 0.92,
    filter: 'blur(4px)',
    ...towards(side, EXIT_OFFSET),
    transition: { duration: 0.12, ease: 'easeIn' },
  },
});

export const floatingVariants: Record<FloatingSide, Variants> = {
  top: floating('top'),
  bottom: floating('bottom'),
  left: floating('left'),
  right: floating('right'),
};

export const floatingOrigin: Record<FloatingSide, string> = {
  top: 'origin-bottom',
  bottom: 'origin-top',
  left: 'origin-right',
  right: 'origin-left',
};

export const backdrop: Variants = {
  hidden: { opacity: 0 },
  visible: { opacity: 1, transition: { duration: 0.25 } },
  exit: { opacity: 0, transition: { duration: 0.15 } },
};

export const surface: Variants = {
  hidden: { opacity: 0, scale: 0.85, y: 16, filter: 'blur(10px)' },
  visible: {
    opacity: 1,
    scale: 1,
    y: 0,
    filter: 'blur(0px)',
    transition: { ...springs.gentle, opacity: { duration: 0.18 }, filter: { duration: 0.25 } },
  },
  exit: {
    opacity: 0,
    scale: 0.9,
    y: 12,
    filter: 'blur(8px)',
    transition: { duration: 0.16, ease: 'easeIn' },
  },
};

const offscreen = (side: FloatingSide, amount: string) => {
  switch (side) {
    case 'top':
      return { y: `-${amount}` };
    case 'bottom':
      return { y: amount };
    case 'left':
      return { x: `-${amount}` };
    case 'right':
      return { x: amount };
  }
};

const slide = (side: FloatingSide): Variants => ({
  hidden: offscreen(side, '100%'),
  visible: { x: 0, y: 0, transition: springs.gentle },
  exit: { ...offscreen(side, '110%'), transition: { duration: 0.2, ease: 'easeIn' } },
});

export const slideVariants: Record<FloatingSide, Variants> = {
  top: slide('top'),
  bottom: slide('bottom'),
  left: slide('left'),
  right: slide('right'),
};

export const collapse: Variants = {
  closed: {
    height: 0,
    opacity: 0,
    transition: { height: springs.snappy, opacity: { duration: 0.1 } },
  },
  open: {
    height: 'auto',
    opacity: 1,
    transition: { height: springs.smooth, opacity: { duration: 0.2, delay: 0.04 } },
  },
};

export const collapseInner: Variants = {
  closed: { y: -10, scale: 0.97, filter: 'blur(4px)', transition: { duration: 0.12 } },
  open: { y: 0, scale: 1, filter: 'blur(0px)', transition: springs.smooth },
};

export const pop: Variants = {
  hidden: { opacity: 0, scale: 0.6 },
  visible: { opacity: 1, scale: 1, transition: { ...springs.snappy, opacity: { duration: 0.1 } } },
  exit: { opacity: 0, scale: 0.8, transition: { duration: 0.1, ease: 'easeIn' } },
};

export const cascade = {
  list: {
    hidden: {},
    visible: { transition: { staggerChildren: 0.035, delayChildren: 0.02 } },
  },
  item: {
    hidden: { opacity: 0, y: 8, scale: 0.9, filter: 'blur(4px)' },
    visible: { opacity: 1, y: 0, scale: 1, filter: 'blur(0px)', transition: springs.snappy },
  },
} satisfies Record<string, Variants>;
```

Three springs cover everything. `snappy` is for hover, press and toggles, `smooth` for panels, menus and collapsibles, and `gentle` for the big surfaces like dialogs. Floating elements open from the side of their trigger and leave faster than they arrived.

## Add your first component

1. Open the page of the component you want, for example [Button](/docs/elements/ui/button).
2. Copy the source from the **Manual** tab.
3. Paste it into the matching folder, in this case `src/components/button.tsx`.
4. If the page lists extra dependencies, install them.
5. Import it and use it:

```tsx
import { Button } from './components/button';

export function App() {
  return <Button>Deploy</Button>;
}
```

Some components use others. When a file imports something like `./label` or `../components/dialog`, copy that component too.

## Dark mode

The dark theme turns on when the `dark` class is on the `<html>` element. Toggle that class however your app handles theme switching.
