Depth in NachUI says two things. What sticks out can be pressed or is floating, and what is sunk can be filled in. Every value is a token in both modes, so a theme changes the depth of the whole catalog at once.

## Raised and sunk

| Utility           | Use                                                                                        |
| ----------------- | ------------------------------------------------------------------------------------------ |
| `shadow-xs`       | Surfaces in the page that cast nothing: islands, secondary buttons, chips, badges          |
| `shadow-sm`       | Cards and controls one step up: card, outline button, active tab, toolbar                  |
| `shadow-md`       | Anchored floating surfaces: popover, hover card, dropdown and context menu, select, toast  |
| `shadow-lg`       | Modal surfaces: dialog, sheet, drawer                                                      |
| `inset-shadow-xs` | Solid fills: primary and destructive buttons, selected day, checked checkbox               |
| `inset-shadow-sm` | Sunk areas, always with `bg-well`: fields, tab and toggle tracks, slider, switch, progress |

The rule of thumb: the further something is from the page, and the more it blocks, the bigger its shadow. Something anchored to a trigger gets `md`; something that takes over the screen gets `lg`. Anything else, like `shadow-xl`, `shadow-2xl` or an arbitrary shadow, is off the table.

## The edge light

All four `shadow` levels start with the same light. In dark mode it is a 1px line set just inside the edge, strongest at the top and almost gone at the bottom, as if lit from above. In light mode white cannot get lighter, so a soft dark edge and a thin lip under the surface do the same job.

It replaces borders. A container never needs one, and a border is left for dividers.

```tsx
<div className="bg-card rounded-lg p-6 shadow-sm">In the flow</div>
<div className="bg-popover rounded-md p-4 shadow-md">Floating</div>
<input className="bg-well inset-shadow-sm rounded-md px-3" />
```

The light is an inset shadow, so a child with an opaque background that reaches the edge covers it. Use a translucent fill such as `bg-well/60` for the header of a card.

## Dark mode

On a dark page a drop shadow alone is hard to see, so dark mode lifts a surface in three ways at once: a lighter fill, the edge light and a stronger shadow. The surfaces step up in lightness as they rise (background 13%, surface muted 18.5%, card 22.5%, popover 25%), which is why every floating surface must use `bg-popover`. A well goes the other way, to 16.5%.
