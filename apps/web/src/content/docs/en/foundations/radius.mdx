Corners in NachUI are soft: controls read as pills and surfaces curve like the edge of a device. Every radius comes from a single token, `--radius`, which is `1.125rem` (18px) in the `nachui` theme. Change it and the whole scale moves together.

## The scale

Tailwind's radius utilities are derived from the base with fixed multipliers. The boxes below use the real utilities, so they follow the site's theme.

<RadiusScale />

| Utility       | Formula           | At 1.125rem | Use                                                   |
| ------------- | ----------------- | ----------- | ----------------------------------------------------- |
| `rounded-sm`  | `--radius * 0.66` | 12px        | Items inside a surface: menu items, tab pill, tooltip |
| `rounded-md`  | `--radius`        | 18px        | Controls, floating surfaces, toasts, callouts         |
| `rounded-lg`  | `--radius * 1.33` | 24px        | Primary containers: cards, dialogs                    |
| `rounded-xl`  | `--radius * 1.66` | 30px        | Composer shells such as the prompt input              |
| `rounded-2xl` | `--radius * 2`    | 36px        | Drawers and other large sheets                        |

```css
@theme inline {
  --radius-sm: calc(var(--radius) * 0.66);
  --radius-md: var(--radius);
  --radius-lg: calc(var(--radius) * 1.33);
  --radius-xl: calc(var(--radius) * 1.66);
  --radius-2xl: calc(var(--radius) * 2);
}
```

Buttons, inputs and select triggers use `rounded-md`. At the `nachui` base that is half the height of a 36px control, so they read as pills; a theme with a smaller base, like `microsoft`, keeps them squarer without touching a component. `rounded-full` is kept for things that stay round in every theme: avatars, status dots, icon-only round buttons and chips.

The checkbox is the one exception below the scale, at `--radius * 0.33` (6px). At 16px wide, `rounded-sm` would make it look like a radio.

## Nesting

An element inside another one always uses a smaller radius than its container. A menu (`rounded-md`) holds items with `rounded-sm`; a card (`rounded-lg`) holds controls with `rounded-md`. When the inner corner matches the outer one, the gap between them looks uneven and the inner element seems to bulge.

<RadiusNesting />

A quick way to check: if you can see the inner corner curve sitting at the same size as the outer one, step it down.
